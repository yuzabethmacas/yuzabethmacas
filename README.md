## 📂 Proyecto Destacado

### 🧠 [MiniShaya](https://github.com/yuzabeth/MiniShaya)

Sistema distribuido de **gestión de alertas en tiempo real** desarrollado bajo una arquitectura de **microservicios y comunicación orientada a eventos**.

El sistema permite la recepción de eventos desde dispositivos o sensores, el procesamiento mediante servicios especializados y la visualización de métricas del sistema en tiempo real.


**Tecnologías utilizadas**
- Java
- Python
- Docker
- Kubernetes
- RabbitMQ
- MQTT (Mosquitto)
- Grafana
